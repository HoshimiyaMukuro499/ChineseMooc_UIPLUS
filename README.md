# 华文慕课 Plus

给 [华文慕课](https://www.chinesemooc.org) 的学习中心换一套更清楚、更安静的界面：一屏看清每门课的视频进度与作业提交状态，课程目录与资料按章节整理，视频页有常驻目录和播放增强。所有数据只在本机解析和保存，不上传任何服务器。

- 版本：2.0.1（Manifest V3）
- 适用浏览器：Microsoft Edge（Chromium 内核）、Chrome
- 作用域：`https://www.chinesemooc.org/*`
- 仓库：[HoshimiyaMukuro499/ChineseMooc_UIPLUS](https://github.com/HoshimiyaMukuro499/ChineseMooc_UIPLUS)

## 安装 / 更新

```bash
git clone https://github.com/HoshimiyaMukuro499/ChineseMooc_UIPLUS.git
```

1. 打开 Edge，地址栏输入 `edge://extensions/` 回车。
2. 打开左下角的 **开发人员模式**。
3. 首次安装：点击 **加载解压缩的扩展**，选择克隆下来的仓库目录。
4. 已经装过旧版：在扩展卡片上点 **重新加载**，然后刷新华文慕课页面。

> Chrome 同理：`chrome://extensions/` → 开发人员模式 → 加载已解压的扩展程序 / 重新加载。

2.0.0 增加了两个内容脚本（`student-data.js`、`student-view.js`）；2.0.1 增加自动连播、截止日提醒和按页面类型抓取。更新后必须重新加载扩展一次才会生效。

## 学习中心

登录后的 `/student/` 不再沿用站点原来的「顶栏 + 左菜单 + 白卡片」，而是按知更的视觉规范重排：白底、黑灰字、一个蓝色强调色、楷体、1px 细线、统计条与文字优先的列表。

### 学习总览（我的主页）
- 48px 顶栏 + 200px 侧栏 + 居中 840px 正文。
- 统计条：已学习分钟、进行中课程、待交作业、已获证书。
- 课程进度列表：课程名、学期/日期、状态、2px 进度条、`23/67 节`、待交作业 `3/8`。
- 待办作业：跨课程汇总，按截止时间排序；有截止时间的作业带「剩 N 天 / 今天截止 / 已截止」标签，越紧迫颜色越重。
- 原站的双栏卡片、日历和课程公告在数据就绪后视觉隐藏；解析失败时保留原页面。

### 我的课程
- 全部 / 进行中 / 已结束分段筛选。
- 每门课一行：标题、学期/模式/日期、进度条与节数、待交作业数、进入课程。

### 课程内部
- 顶部 64px 课程条：课程名、学期、学校/教师、开课日期；课程统计放进正文统计条。
- 统计条：视频进度（来自个人中心，如 `23/67`）、待交作业、课程资料数、章节数。
- 章节折叠列表：全部 / 视频 / 作业 / 资料筛选；作业状态区分「待完成」「可提交」「已完成」。
- 作业链接按站内 `gopaper(homeworkid, sort)` 规则还原成可点击的作业详情页。
- 资料视图：按章分组，支持搜索和文件类型筛选；数据来自 `student_download_courseware.php`，解析不到时给出资源下载页入口。

### 视频页
- 播放器保持原站 `#player-con` 的 810×455 尺寸和 DOM，不移动、不替换。
- 播放器右侧新增常驻课程目录：按章分组、显示时长、高亮当前视频、自动滚到当前项。
- 播放器下方摘要条：本课进度、待交作业、课程资料入口、课程目录入口。
- 自动连播：一节播完后右下角出现 5 秒倒计时，可立即播放或取消；控制条上的「连播」可随时开关，状态会记住。
- 保留 0.75×–2× 倍速、画中画、宽屏模式和快捷键。

## 其他功能

- 全站明暗主题：跟随系统 / 强制浅色 / 强制深色。
- 视频快捷键：`空格` 播放/暂停，`← / →` 后退/前进 5 秒，`↑ / ↓` 音量，`F` 全屏，`P` 画中画，`[ / ]` 调整倍速。
- 页面右下角工具条：切换主题、课程笔记（详情页）、收藏当前页、回到顶部。
- 扩展弹窗：主题、视频增强开关、学习数据摘要与刷新、收藏与笔记管理。

## 数据与隐私

- 设置、笔记、收藏、规范化学习数据保存在 `chrome.storage.local`，仅本机可见。
- 学习数据通过**同源请求**读取：扩展在已登录的页面里请求 `chinesemooc.org` 自己的页面（个人中心、我的课程、课程目录、资源下载页），浏览器自动带上当前会话。
- **不读取、不复制、不上传 Cookie**；没有第三方服务器参与；不上传任何学习数据。
- 内存缓存 10 分钟，最多读取 30 门课，并发 6 个请求；课程目录与资料页并行抓取。
- 按页面类型按需抓取：总览只抓进行中课程的目录（用来排待办截止日期），课程列表只更新进度，课程页只抓当前这门，视频页只更新个人中心与课程列表（视频目录直接来自当前页面）；没打开过的课程不会反复请求。
- 课程目录与资源页解析全部是防御式的；结构变化导致解析失败时，页面保留原站 UI，不会把内容清空。
- 卸载扩展即清除全部本地数据。

## 已知限制

- 视频课程页本身没有逐条「已看」标记；每门课的完成节数只从个人中心/我的课程的 `23/67 节` 读取，不伪造单条视频状态。
- 资源下载页没有在开发时完整抓取，资料解析以文件扩展名和链接文字为主；如果站点用了特殊下载入口，可能只能看到资源页链接。
- 站点改版后 DOM 结构若变化，选择器可能需要同步调整；解析失败会回退到原站 UI。
- 学习数据刷新需要已登录的页面处于打开状态；弹窗里的「刷新学习数据」会通知当前标签页执行刷新。
